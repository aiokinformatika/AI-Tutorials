# AI & Machine Learning Tutorials

A collection of practical, reproducible tutorials covering
AI, machine learning, local LLMs, software development,
and supporting infrastructure.

## Tutorials

| Tutorial | Description |
|----------|-------------|
| [Debian 13 & Docker Development Environment](docker-test/) | Set up and verify a development environment using Debian 13, Docker, Docker Compose, and PyCharm. |

## Repository Structure

Each tutorial has its own directory containing:

- README.md with step-by-step instructions
- Source code and configuration files
- Prerequisites and execution instructions
- Expected results and troubleshooting guidance

## Requirements

Requirements vary by tutorial. See the README.md
inside each tutorial directory.
